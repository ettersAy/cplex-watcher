    Bot command guide

    Send commands in your private Telegram chat with the bot.

    🎟 Seat watcher

    Add theatre details and seat labels in the web interface. Telegram is for quick showtime management and details.

    /watchshowtime Dune 405740,405741Start watching comma-separated showtime IDs.
    /stopshowtime Dune 405741Stop one watched showtime.
    /stopseats DuneStop the complete seat watch, including every showtime.
    /refreshseats DuneRequest an immediate seat check for one watch.
    /listseatsShow a short summary of all seat watches.
    /seatinfo DuneShow available and still-watched showtimes, grouped by day.

    🎫 Ticket watcher

    Watch a movie until Cineplex starts selling tickets.

    /watch Dune: Part 3Start a ticket-sale watch.
    /stopwatch Dune: Part 3Stop a ticket-sale watch.
    /listList current ticket-sale watches.

    🔐 Access

    Use this only in a private chat with the bot.

    /idShow your Telegram chat ID so the owner can authorize it.

    How seat alerts work

    A matching seat alerts once when it becomes available. It is not alerted again while it stays available. If it disappears and later reopens, the bot alerts again. Scan failures are sent to Telegram and written to logs.
